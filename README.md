# Bowling Tracker
C++ Bowling Tracker

Current bowling trackers cost money or aren't good enough. A lot of them lack basic features that are super useful.

C++ program that can take in game data and store in as files for the User to view at later times. It will also include useful features such as Average Score, Common Splits, and Score Predictions if you strike or spare once more.

Using no external libraries, I will store the game data in a custom file format so that it takes up as little space as possible. This enables storage of a very high amount of games in a small format.

## Plan
- Create game storage file format.
- Create User input and convert games to the custom format.
- Implement game statistics.
- Create pin leaves/common spares.
- Implement game evaluation (+1 strike/spare score).
